英会話のシャドーイング練習用の音楽プレイヤーです。バー上に**アンカー（Anchor）**を置き、ワンキー（Space）でその位置へ戻って再生を続けられます。

An audio player for shadowing practice — drop an anchor anywhere on the bar and jump back to it with one key (Space).

## v0.7.4 の変更 / Changes

操作や画面の変更はありません。**内部の信頼性を上げるための版**です。

- 🛟 **音源の読み込みに失敗したときの挙動を改善**しました。これまでは前のファイル名が画面に残ったままになり、「再生を押しても鳴らない」状態になることがありました。失敗した場合は最初の画面に戻ります。
- 🔔 **再生やシークに失敗したときに、画面で知らせる**ようにしました。以前は何も表示されず、操作が効かない理由が分かりませんでした。
- 🧪 **中核動作の自動テストを追加**しました（アンカーの範囲、アンカーへ戻る順序、操作が重なったときの順序、読み込み時のリセットなど）。
- 🔊 **読み上げソフト向けの情報**をシークバーに追加し、再生位置とアンカーを区別できるようにしました。
- 📖 **説明の誤りを修正**しました（再生速度の記載が `0.5〜2.0x` のままだった点など）。

No changes to how the app looks or behaves. This release improves internal reliability: better recovery when a file fails to load, visible feedback on playback errors, automated tests for the core anchor/seek paths, and screen-reader labels on the seek bar.

## 覚えておくとよい動作

- **音源を開くと、アンカーと再生位置は必ず0秒に戻ります。** 前回どこにアンカーを置いて終えたかは持ち越しません。
- 開いた1ファイルを常にエンドレスリピートします。
- 最初の画面に、最近開いたファイルが5件並びます。

## ダウンロード / Downloads

**Windows はインストーラを推奨します。**

| ファイル | 用途 |
|---|---|
| `AnchorPlayer-Setup-0.7.4.exe` | **推奨**。ダブルクリックで導入 |

| `anchor-player-v0.7.4.apk` | Android（実験的対応・個人利用向け） |

※ 署名がないため、初回起動時に SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
※ Android はデバッグ署名のため正式署名ではありません。
