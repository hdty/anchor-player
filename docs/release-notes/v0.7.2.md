英会話のシャドーイング練習用の音楽プレイヤーです。バー上に**アンカー（Anchor）**を置き、ワンキー（Space）でその位置へ戻って再生を続けられます。

An audio player for shadowing practice — drop an anchor anywhere on the bar and jump back to it with one key (Space).

## v0.7.2 の変更 / Changes
- 📦 **Windows インストーラを用意しました**。`AnchorPlayer-Setup-0.7.2.exe` をダブルクリックするだけで導入できます。
  - スタートメニューへの登録とアンインストーラが付きます。
  - インストール時に「**すべてのユーザー**」（`C:\Program Files\AnchorPlayer`）か「**自分だけ**」（`%LOCALAPPDATA%\Programs\AnchorPlayer`）を選べます。既定は「自分だけ」で、管理者権限は不要です。
- 🐛 **ヘルプの一覧の最後の項目（`9`/`E` = Anchor +5s）が見えなかった問題を修正**しました。v0.7.1 でバージョン表示を足した際に押し出されていました。

A Windows installer is now available — no need to unzip a folder full of DLLs. Also fixes the last shortcut row being pushed out of the help dialog in v0.7.1.

## ダウンロード / Downloads

**Windows はインストーラを推奨します。**

| ファイル | 用途 |
|---|---|
| `AnchorPlayer-Setup-0.7.2.exe` | **推奨**。ダブルクリックで導入 |
| `anchor-player-v0.7.2-windows-x64.zip` | インストールせずに使いたい場合。展開して `AnchorPlayer\anchor_player.exe` を実行 |
| `anchor-player-v0.7.2.apk` | Android。端末に転送し、ファイルアプリから開いてインストール |

※ 署名がないため、初回起動時に SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
※ Android はデバッグ署名のため正式署名ではありません（個人利用向け）。
