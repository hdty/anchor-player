英会話のシャドーイング練習用の音楽プレイヤーです。バー上に**アンカー（Anchor）**を置き、ワンキー（Space）でその位置へ戻って再生を続けられます。

An audio player for shadowing practice — drop an anchor anywhere on the bar and jump back to it with one key (Space).

## v0.7.3 の変更 / Changes

アプリの機能は v0.7.2 と同じです。**このリリースから、配布物を GitHub Actions が自動でビルドするようになりました。**

- 🤖 **リリースの自動化**。タグを打つと、GitHub 上で解析・テスト・ビルド・インストーラ生成までが自動で走ります。手元の PC でビルドしたファイルは配布しません。
- 🔍 ビルドのたびに `flutter analyze` と `flutter test` が必ず実行され、同梱ライブラリの検査も行われます。
- 📌 タグと内部バージョンの不一致を機械的に検出します。

これは将来 [SignPath Foundation](https://signpath.org/) の無償コード署名を受けるための準備でもあります（「バイナリがソースコードからの自動ビルドであること」が要件のため）。署名が付けば、初回起動時の SmartScreen 警告が出なくなります。

Builds are now produced by GitHub Actions instead of a local machine — a prerequisite for free code signing from the SignPath Foundation.

## ダウンロード / Downloads

**Windows はインストーラを推奨します。**

| ファイル | 用途 |
|---|---|
| `AnchorPlayer-Setup-0.7.3.exe` | **推奨**。ダブルクリックで導入 |
| `anchor-player-v0.7.3-windows-x64.zip` | インストールせずに使いたい場合。展開して `AnchorPlayer\anchor_player.exe` を実行 |
| `anchor-player-v0.7.3.apk` | Android。端末に転送し、ファイルアプリから開いてインストール |

※ まだ署名がないため、初回起動時に SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
※ Android はデバッグ署名のため正式署名ではありません（個人利用向け）。
