# Anchor Player アイコン設計図（blueprint）

実装側への引き渡し用。形状の実体は [`lib/ui/anchor_mark.dart`](../lib/ui/anchor_mark.dart)、
参照用ベクタは [`anchor_mark.svg`](anchor_mark.svg)。この文書はその根拠（寸法・配色・描画順）を1枚にまとめる。

## コンセプト（ヒエラルキー）

このアプリの**主機能は音声ファイルの再生**で、アンカーはその再生を助ける重要な補助機能。
図案もその序列に従う:

- **主役 = 大きな再生三角**（＝プレイヤー）。アイコンの中心を占める。
- **従 = 右下の半分サイズのアンカー**。バッジとして少しだけ三角に重ねる。
- アンカーの周囲に**地の色の「逃げ」**を入れて三角から浮かせる（濁り防止・小サイズでの分離）。

小サイズ（16–20px）では再生三角だけが明快に残り、アンカーは大サイズで効くアクセントになる。
これは「主機能は小さくても伝わり、補助機能は大きいときに現れる」という序列と一致する。

## グリッド

- 基準グリッド **96 × 96**（Material Symbols の 24px グリッド ×4）。
- 角丸プレート半径 **22**。
- 均一ストローク・丸終端（Material Symbols Rounded weight 400 相当）。

## 座標（96 グリッド）

### 再生三角（主役・塗り）
頂点 `(32,22) → (32,74) → (74,48)` の塗り。角を丸めるため、同色で
`stroke-width 5 / stroke-linejoin round` を重ね描きする。

### アンカー（右下バッジ）
| 部位 | 幾何 |
|------|------|
| リング | 中心 `(63,53)`、半径 `4`、線 |
| シャンク | `(63,57) → (63,72)` |
| ストック | `(54,62) → (72,62)` |
| フルーク | `M52 68  Q52 76 63 76  Q74 76 74 68` |

ストローク幅は2段構え:

| | 本体（薄桜） | 逃げ（地色で抜く） |
|---|---|---|
| リング | 3.5 | 7.5 |
| シャンク / ストック / フルーク | 5 | 9 |

逃げは本体より各 +4 太い。三角をこの太い形で抜き、抜けた中に細い本体を載せる。

## 配色（確定 = 順列3「地紺 / 再水 / 錨薄桜」）

| 役割 | 色 | HEX |
|------|-----|-----|
| プレート（地）／逃げ | インクネイビー | `#13253F` |
| 再生三角 | 水色 | `#A3D8E1` |
| アンカー | 薄桜色（HidéToys） | `#E8AFCF` |

- 逃げ（隙間）は**常にプレートと同色**。プレートを描かない前景では透明で抜き、
  背景レイヤ（紺）が隙間として覗く。
- アイコンのアンカーは**薄桜 `#E8AFCF`**。淡いため装飾には最適。
  一方、アプリ UI の機能色（ボタン・文字）は白地でのコントラスト確保のため
  **濃い桜 `#C9457E`**（`AnchorColors`）を使う。アイコン＝薄桜／UI機能色＝濃桜で役割分担する。

## 描画順（`AnchorMark.paintOn`）

1. プレート（角丸 rx22、紺）。※前景生成時は描かない。
2. `saveLayer` 開始。
3. 再生三角（水色・塗り＋丸め用ストローク）。
4. アンカー形（逃げ幅）を `BlendMode.clear` で**抜く** → 地が覗く。
5. `saveLayer` 復元。
6. 逃げの中に細いアンカー（薄桜）を載せる。

## 生成物とパイプライン

```bash
flutter test tools/gen_icon.dart      # design/icon_*.png と前景/monochrome を書き出す
powershell -File tools/make-icon.ps1  # PNG を windows/runner/resources/app_icon.ico にパック
dart run flutter_launcher_icons       # Android / iOS を生成
```

| 生成物 | 三角 | アンカー | プレート | 備考 |
|--------|------|----------|----------|------|
| `icon_{16..1024}.png` | 水色 | 薄桜 | 紺 | Windows .ico とランチャーの元 |
| `icon_foreground_1024.png` | 水色 | 薄桜 | なし（透明） | Android アダプティブ前景。セーフゾーン 66/108 に縮小 |
| `icon_monochrome_1024.png` | 紺（単色） | なし | なし | Android テーマ付き。単色化で逃げが「欠け」に見えるため三角のみ |

- Android アダプティブ背景（`pubspec.yaml` の `adaptive_icon_background`）＝ `#13253F`。
- セーフゾーン縮小率 `66/108`（`AnchorMark` の `scaleFactor`）。

## 変更するとき

- 形状は `AnchorMark`（`lib/ui/anchor_mark.dart`）が唯一の定義。この SVG とこの文書は手で追随させる。
- 直したら `flutter test tools/gen_icon.dart` → `make-icon.ps1` → `flutter_launcher_icons` を回し、
  `icon_16.png` / `icon_32.png` を実寸で見て三角＝プレイヤーが成立するか確認する。
